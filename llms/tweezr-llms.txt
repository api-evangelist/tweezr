# Tweezr

> Tweezr is a system-intelligence platform for safe legacy change. It maps mainframe and heritage financial systems (COBOL, PL/I, CICS, IMS, DB2 z/OS, VSAM, IBM i RPG, Adabas/Natural) into a deterministic, queryable, cited model so engineering teams and AI tools know exactly what a legacy core does before changing it. Deployed on-premise by default for banks and insurers; no public API or developer program is published as of July 2026.

Tweezr is a Techstars portfolio company, a member of the Banking Industry Architecture Network (BIAN), and a partner of 10x Banking. The product is distributed through AWS Marketplace and Microsoft AppSource.
